# TaskFlow — Zen Productivity To-Do App

A clean, modern, and responsive to-do application designed for personal focus and daily task organization.

## ✨ Features

- **Task Management**: Create, edit, star, prioritize (High, Medium, Low), categorize, and check off tasks.
- **Smart Views**:
  - 📥 **All Tasks**: Complete overview of active items.
  - ☀️ **Today**: Items due today and overdue active items.
  - 📅 **Upcoming**: Scheduled future tasks.
  - ⭐ **Starred**: Pinned important tasks.
  - ✅ **Completed**: History and log of finished items.
- **Subtasks & Notes**: Nested checklist progress for complex tasks and expandable note areas.
- **Integrated Pomodoro Timer**: 25m Focus / 5m Short Break / 15m Long Break sessions with optional task linkage.
- **Interactive Audio & Celebrations**: Procedural Web Audio API sound chimes and a celebration confetti engine.
- **Productivity Dashboard**: Real-time completion rates, category stats, and daily streak progress.
- **Data Backup & Restore**: Export and import your data as JSON anytime.
- **Dark & Light Mode**: Seamless theme switching with system preference detection.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| `N` | Quick Add a new task |
| `/` or `Ctrl + K` / `Cmd + K` | Focus task search bar |
| `P` | Open Pomodoro focus timer |
| `D` | Toggle Dark / Light theme |
| `Esc` | Close active dialogs / modals |
